## Goal
`ctx.approve` raises its card with `approvals.request_nowait` and the run leaves the process (status `parked`); the plugin resumes the segment loop itself on `approval.decided`, never through the orphan continuation turn. `ctx.wait_event(name, filter=, timeout=)` parks on a bus subscription and survives a restart via an `on_server_ready` reconcile. A park is bounded by the card TTL / the wait timeout and, above both, by the run `max_duration` (24 h default), which fails the park loudly; `cancel_run` on a parked run releases the card or subscription; every resume path re-checks `status == "parked"` first. Today neither wait exists: `_run_wait_for_approval` auto-approves (`runner.py:1060-1069`) and `_run_wait_for_event` returns `{"received": False, "stub": True}` (`:1071-1083`); the v1 runner is left as is — only python-format runs park.
