## Goal
Every run-shaped result says what it is before it says anything else, and one read-only tool gives the keyhole the derived truth about a playbook.

Today, at 8c31a60: `_run` (agent_tools.py:520-532) names the live version only inside a `note` string and only when `playbook.candidate_version` is set; `_dry_run` (:1572-1633) forwards the v1 runner's `status: "done"` (runner.py `dry_run` :557-600 defaults `status = "done"`) under a `banner`; `_status` (:626-640) has no version and no mode; `_run_candidate` (:2704-2714) returns `candidate_version` but no role or side-effects flag; `_runs` (handler `_runs_read`, :1369-1428) entries (:1393-1402) carry `version`/`is_test` but no kind.

After this phase the five tools open with `{kind, side_effects, version, version_role, run_id}`, simulated results are `simulated` never `done`, `playbook_overview(name)` exists (manifest 25 → 26 tools), every `next` hint points at it, and both authoring skills carry the rule "quote `kind` + `version` when reporting a run". This phase does not claim to fix 0056 ("dry run sold as a real instant run") on its own — the envelope is paired with the skill rule and measured at plugin/11 / dojop/02 (master §2 Result provenance, §3 Success criteria).
