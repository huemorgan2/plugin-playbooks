## Goal
After this phase a v2 run is indistinguishable from a v1 run to every consumer master §1 item 13 lists — wake, fix proposals, failure digest, trust badges, the test_run gate, `playbook.saved`, heartbeats, `report_to`, trigger input shapes, edit tickets, duplicate-row healing, mint-above-max, archived-name takeover, the delegation card — except for one additive `result` key. `format` is stamped per version and per run so a python candidate can sit next to a pblang live version and each runs under its own runtime, which is what plugin/12's migration edits need.
