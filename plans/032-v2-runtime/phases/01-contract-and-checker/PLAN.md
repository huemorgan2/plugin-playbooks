The contract table (`docs/v2.md` §2), one row per effect, columns `Effect | Signature | Returns | Raises | Options | Status`; values decided by master §2 Language, gaps filled by the assumptions in "Risks and open questions":
- `ctx.tool(name, /, **args)` — `name` a string literal, positional-only (so a tool parameter called `name` still works); returns the parsed result unwrapped (what `_normalize_tool_result` yields, runner.py:138-153); raises `ToolError`, `EffectTimeout`, `OutcomeUnknown`; options `_id`, `_timeout`, `_retry`.
- `ctx.llm(prompt, *, output=None, purpose=None, model=None, system=None)` — dict when `output` given, else `str`; raises `EffectError`, `EffectTimeout`; options `_id`, `_timeout`, `_retry`.
- `ctx.agent(prompt, *, output=None, tools=None)` — same return rule; raises `EffectError`, `EffectTimeout`, `OutcomeUnknown`; transcript attached to the journal row (plugin/03); options as llm.
- `ctx.subtask(playbook, inputs=None, *, returns=None)` — `playbook` a string literal; returns the child's return value (`returns=` picks keys from it, see Risks); raises `SubtaskFailed`, `EffectTimeout`, `OutcomeUnknown`; options `_id`, `_timeout`.
- `ctx.gather(*effects)` — arguments are un-awaited effect calls; results in argument order; journal `seq` in argument order; first failure raised after all settle; no options.
- `ctx.approve(*, show)` — returns `{"approved": True, "approval_id": <str|None>}`; raises `Rejected`, `ApprovalExpired`; option `_id`. In-process form plugin/03, park form plugin/07.
- `ctx.wait_event(name, *, filter=None, timeout)` — `timeout` (seconds) REQUIRED; returns the event payload dict; raises `EventTimeout`; option `_id`. Status: unavailable until plugin/07 (checker rejects it, R10).
- `ctx.now()` → tz-aware UTC `datetime`, journaled as ISO-8601; `ctx.random()` → float in `[0.0, 1.0)`, journaled; `ctx.log(msg)` → `None`, journaled seq-tagged; option `_id` on each; re-executed (not replayed as unknown) after a crash — master §2 Execution model.
- `ctx.sleep(seconds)` — deferred (master §3 Deferred); rejected in every phase (R10).
Options: `_id: str` literal, unique per call site; `_timeout: int|float` seconds (defaults per kind in §12: tool 120, llm 300, agent 900, subtask none); `_retry: int | {"attempts": int, "backoff": float}` — host-side, ONE journal row with an `attempts` list, retries `ToolError`/`EffectTimeout` only, never `OutcomeUnknown`/`Rejected`. `_timeout` is enforced for every kind (plugin/02); a caught effect failure is journaled `failed_handled` and never hoisted onto the run status (master §2 Language).
§4 Exceptions: `EffectError(Exception)` ← `ToolError`, `EffectTimeout`, `OutcomeUnknown`, `Rejected`, `ApprovalExpired`, `EventTimeout`, `SubtaskFailed`; `RunCancelled`, `JournalDivergence`, `EffectLimitExceeded` derive from `BaseException` and cannot be caught (R19). §6 Journal: entry 0 `{seq: 0, kind: "run", hash_seed, inputs, playbook, version, format, mode: "real"|"dry", max_effects, started_at}`; effect rows `{seq, kind, id, occurrence, args (raw vault refs, never resolved), idempotency_key: "<run_id>:<seq>", status: in_flight|done|failed|failed_handled|timed_out_unknown|parked, result, error: {type, message}, attempts: [...], dry: bool, started_at, ended_at}` plus `transcript` (agent, plugin/03) and `parked_on` (plugin/07). §7 Error contract: issue shape above; compile under `stable_filename` with line offset 0 (the shim must `compile()` the saved source from a string — luna-fixer `inline-code-run-plan.md` §2, last paragraph: the jail's own wrap shifts lines by 5); `outputs/error.json` `{error_type, message, traceback (frames filtered to the playbook filename), playbook_line, last_completed_effect {seq, id, kind}, locals_preview (repr ≤ 200 chars, vault refs masked)}`; `outputs/progress.json` `{seq, phase}` before every effect exit; `print` rejected, stdout silenced, `ctx.log` is the only author output; one-line failed result `line 7: rows['items'] → KeyError after effect fetch#1`; `failure_signature` keys on (playbook, failed line or effect id, error head).

Checker rules (each a `RULES` entry; `severity` error unless marked warning; every issue carries `expected` and a concrete `example_fix`):
- R1 `v2-syntax` — `SyntaxError` from `ast.parse(code, filename)`: one issue at `(e.lineno, e.offset-1)`, nothing else runs (v1 parity: compiler.py:1129-1133).
- R2 `v2-entry-point` — exactly one top-level `async def run(ctx, inputs)`: missing, duplicate, sync `def run`, other parameter names/count, defaults, `*args`/`**kw`, or `yield` inside `run`.
- R3 `v2-top-level` — top-level statements other than a docstring, whitelisted imports, `def`/`async def` helpers and `NAME = <literal>` constants; any `class` anywhere.
- R4 `v2-import` — module not in the whitelist `json, re, math, datetime, textwrap, itertools, collections, functools, operator, string, decimal, fractions, statistics, typing, dataclasses, enum, base64, hashlib, html, difflib, heapq, bisect, copy, unicodedata`; module-specific steers: `time` → `ctx.now`, `random`/`uuid`/`secrets` → `ctx.random`, `asyncio` → `ctx.gather` (and "ctx.sleep is not available"), `os`/`sys`/`subprocess`/`socket`/`pathlib`/`io`/`requests`/`httpx`/`urllib` → "no I/O; the world is reached through ctx.tool".
- R5 `v2-banned-name` — calls to `open, exec, eval, compile, __import__, input, breakpoint, globals, locals, vars, exit, quit, help`; attribute access to `__class__`, `__dict__`, `__globals__`, `__builtins__`, `__subclasses__`.
- R6 `v2-use-ctx-now` — `datetime.now/utcnow/today`, `date.today`, `time.time/monotonic/perf_counter`. R7 `v2-use-ctx-random` — any `random.`/`uuid.`/`secrets.` call. R8 `v2-use-ctx-log` — `print(`. R9 `v2-use-ctx-gather` — `asyncio.gather/create_task/wait/as_completed`.
- R10 `v2-effect-unavailable` — `ctx.sleep` (always), `ctx.wait_event` when `"wait_event"` is not in `features`, `asyncio.sleep`, `time.sleep`; message contains "not available in this version".
- R11 `v2-unknown-ctx-attr` — `ctx.<x>` not in `AVAILABLE_EFFECTS | UNAVAILABLE_EFFECTS | CTX_EXCEPTIONS | CTX_UNCATCHABLE`, with a `difflib` did-you-mean.
- R12 `v2-effect-not-on-ctx` — bare `tool(`, `llm(`, `agent(`, `approve(`, `subtask(`, `gather(`, `wait_event(`, `code(`, `loop(`, `if_(`, `state(`, `halt(` (the pblang step-name table, compiler.py:62-71) or a `playbook(` header inside python code, or an effect name called on a receiver other than the Name `ctx`.
- R13 `v2-missing-await` — an effect call that is not the operand of `await`, not a direct/starred argument of `ctx.gather(...)`, and not an element of a list/comprehension whose only use is `*name` inside `ctx.gather(...)`.
- R14 `v2-tool-name-literal` — `ctx.tool`/`ctx.subtask`/`ctx.wait_event` first argument missing or not a string constant; extra positional arguments on `ctx.tool`.
- R15 `v2-unknown-kwarg` — keyword or positional argument outside the signature table (llm: prompt, output, purpose, model, system; agent: prompt, output, tools; approve: show — required; subtask: playbook, inputs, returns; wait_event: name, filter, timeout — required; now/random: none; log: msg); `expected` lists the accepted names.
- R16 `v2-option` — unknown `_x` option; `_id` not a string constant; `_timeout` not a number; `_retry` not int/dict; an option on a kind that does not take it. R16b `v2-duplicate-call-site-id` (warning) — two call sites resolve to the same id (see ids below).
- R17 `v2-unknown-tool` — only when `tool_names` is given: literal not in the set (v1 parity: validation.py:520-528).
- R18 `v2-broad-except` — `except:` / `except Exception` / `except BaseException` whose `try` body contains an effect call at any depth → "catch ctx.EffectError (or ctx.ToolError …)". R19 `v2-uncatchable` — `except ctx.RunCancelled` / `ctx.JournalDivergence` / `ctx.EffectLimitExceeded`.
- R20 `v2-inputs-attr` — `inputs.<name>` attribute access (the pblang habit) → `inputs["name"]`; the bare Names `steps`, `vars`, `event` → "no such namespace in v2". R21 `v2-unknown-input` (warning, only with `inputs_schema`) — `inputs["k"]` with `k` not in `properties`.
- R22 `v2-set-iteration` (warning) — `for`/comprehension/`join`/`list(...)` over a set display, set comprehension, `set(...)` call, or a Name bound to one in the same function → `sorted(...)`. R23 `v2-nondeterministic-builtin` (warning) — `hash(`, `id(`.
- R24 `v2-too-many-call-sites` (warning) — more than 40 static effect call sites. R25 `v2-effect-in-nested-loops` (warning) — a call site at loop depth ≥ 2, message names `MAX_EFFECTS = 200`. R30 `v2-gather-args` — a `ctx.gather` argument that is not an effect call (a nested gather, a helper coroutine, a plain value). R29 `v2-async-construct` — `async for` / `async with`.
- R26 ported v1 lints, same codes, same severities, same prompt heuristics: `monolithic-playbook` (error; validation.py:798-827 — exactly one non-delivery effect call site in `run`, it is `ctx.llm`/`ctx.agent`, and its prompt trips quantifier/sequence/multi-op-I/O or reads a collection; delivery = `ctx.tool("send_chat_message", …)`, :739-741), `compound-leaf` (warning; :756-776 — a non-looped llm/agent prompt with quantifier/sequence/≥ 2 operations), `agent-does-work` (warning; :779-795 — `ctx.agent` with I/O verbs and no judgment cue), `context-economy` (warning; :693-717 — a non-looped llm/agent whose f-string prompt interpolates an array-typed input, a whole `ctx.tool` result, or a subscript ending in a `_DEEP_COLLECTION_REF` word). Prompt text = the string constant or the constant parts of an f-string.
