## Goal
A v2 playbook (`async def run(ctx, inputs)`, checker-admitted in plugin/01) executes end to end through the real jail on segmented replay: the host writes the journal, the jail replays it and emits the next effect, the host journals FIRST, executes with v1 parity, and re-invokes — until `run()` returns or raises. Runtime errors land as the master's error contract on the run row, `_timeout` is enforced per effect, MAX_EFFECTS and journal divergence fail loud, `print` is silent, and the hash-seed pin is decided (option A or B) by the set-iteration replay test. The journal is in memory; a restart still kills a v2 run (v1 parity) and the row says so.
