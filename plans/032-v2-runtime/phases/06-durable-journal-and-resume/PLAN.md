## Goal

A v2 run survives a process death. The journal lives in a table the plugin creates on load; every effect is committed as an `in_flight` row before it executes; a restart finds the `running` v2 rows in `on_server_ready`, marks in-flight tool/agent/subtask rows `timed_out_unknown` (never re-executed), re-executes in-flight llm/now/random (and log, Risks 15) rows in place, and continues each run from its journal on the exact version row it started on, ending with the same `playbook.run.completed` payload a never-interrupted run emits. The replaying segment sees a lost outcome as `ctx.OutcomeUnknown` — catchable; uncaught, the run ends with status `timed_out_unknown`. v1 runs keep today's sweep-to-failed; v2 `running` rows leave the sweep. The phase-02 interim rule "a restart still kills a v2 run and the row says so" is gone from code, tests and `docs/v2.md`.
